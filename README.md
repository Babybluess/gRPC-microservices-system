# grpc-shop

gRPC microservices system in Go with Protobuf, Consul service discovery, mutual TLS, OpenTelemetry tracing, and client-side load balancing.

## Prerequisites

- Go 1.22+
- [mkcert](https://github.com/FiloSottile/mkcert) — local TLS certificates
- [consul](https://developer.hashicorp.com/consul/install) — service registry (install via `brew install consul`)
- Docker — Jaeger tracing backend
- protoc + plugins (only needed to regenerate protos):
  ```bash
  go install google.golang.org/protobuf/cmd/protoc-gen-go@latest
  go install google.golang.org/grpc/cmd/protoc-gen-go-grpc@latest
  ```

## Setup

### 1. Install mkcert and generate TLS certificates

```bash
brew install mkcert
sudo mkcert -install          # adds the local CA to the system trust store (needs sudo once)

mkdir certs
mkcert -cert-file certs/server.pem -key-file certs/server-key.pem localhost 127.0.0.1 ::1
cp "$(mkcert -CAROOT)/rootCA.pem" certs/ca.pem
```

The `certs/` directory is gitignored — never commit private keys.

### 2. Install Go dependencies

```bash
go mod tidy
```

### 3. Regenerate protobuf code (only if .proto files change)

```bash
make proto
```

## Running

Start each component in a separate terminal, in order.

```bash
# Terminal 1 — Consul service registry
consul agent -dev

# Terminal 2 — Jaeger tracing UI  (http://localhost:16686)
docker run -d --name jaeger -p 16686:16686 -p 4317:4317 jaegertracing/all-in-one:latest

# Terminal 3 — user-service  (gRPC :50051)
go run services/user/main.go

# Terminal 4 — order-service  (gRPC :50052)
go run services/order/main.go

# Terminal 5 — gateway (demo client: registers a user, creates an order, lists orders)
go run gateway/main.go
```

Wait ~10 s after starting a service before running the gateway — Consul needs at least one health-check cycle to mark instances as healthy.

## Inspect with grpcurl

Services now require TLS. Pass `-cacert` and the auth header:

```bash
grpcurl -cacert certs/ca.pem \
  -H "authorization: Bearer secret-token" \
  -d '{"email":"bob@test.com","name":"Bob"}' \
  localhost:50051 user.UserService/Register
```

## Consul UI

http://localhost:8500 — shows registered services and their health-check status.

## Jaeger UI

http://localhost:16686 — select service `gateway` to see the full distributed trace across all three processes.

Override the OTLP endpoint (e.g. for Grafana Tempo):
```bash
OTEL_EXPORTER_OTLP_ENDPOINT=my-tempo:4317 go run services/user/main.go
```


## Architecture

```
gateway
  │  TLS + round-robin (consul resolver)
  │  W3C traceparent propagated in gRPC metadata
  ├─► user-service  :50051
  │     interceptors: logger → tracing → auth
  └─► order-service :50052
        interceptors: logger → tracing → auth

Consul :8500   — health checks every 10 s via gRPC health protocol
Jaeger :4317   — receives OTLP spans; UI on :16686
```

## Interceptor chain

| Interceptor | Side | Purpose |
|---|---|---|
| `UnaryLogger` | server | logs every RPC with method, duration, error |
| `UnaryTracing` | server | extracts `traceparent` from metadata, starts server span |
| `UnaryAuth` | server | validates `authorization: Bearer <token>` header |
| `UnaryClientTracing` | client | starts client span, injects `traceparent` into outgoing metadata |
| `StreamClientTracing` | client | same as above for server-streaming RPCs |

Health-check calls (`/grpc.health.v1.Health/Check`) bypass `UnaryAuth` — Consul probes carry no application token.
