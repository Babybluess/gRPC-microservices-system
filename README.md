# grpc-shop

gRPC microservices system in Go with Protobuf and Consul service discovery.

## Prerequisites

- Go 1.22+
- Docker (for Consul)
- protoc + plugins:
  ```bash
  go install google.golang.org/protobuf/cmd/protoc-gen-go@latest
  go install google.golang.org/grpc/cmd/protoc-gen-go-grpc@latest
  ```

## Setup & Run

```bash
# 1. Start Consul
docker run -d --name consul -p 8500:8500 hashicorp/consul agent -dev

# 2. Generate protobuf code
make proto

# 3. Install dependencies
go mod tidy

# 4. Start services (separate terminals)
go run services/user/main.go
go run services/order/main.go

# 5. Run the gateway
go run gateway/main.go
```

Consul UI: http://localhost:8500

## Inspect with grpcurl

```bash
grpcurl -plaintext -H "authorization: Bearer secret-token" \
  localhost:50051 user.UserService/Register \
  -d '{"email":"bob@test.com","name":"Bob"}'
```

## Layout

```
grpc-shop/
├── proto/
│   ├── user/user.proto
│   └── order/order.proto
├── gen/                        generated by protoc (run make proto)
├── services/
│   ├── user/main.go            UserService  :50051
│   └── order/main.go           OrderService :50052
├── gateway/main.go             API Gateway
├── internal/
│   ├── discovery/consul.go     register / discover via Consul
│   └── interceptors/           logging + auth interceptors
└── Makefile
```
